An entry for the [make.fun](https://make.fun/c/u-suroto-worst-superpower-461dcdbe)
bounty "Worst Superpower" — invent the most useless superpower in one line
of at most 140 characters.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> I can turn invisible, but only to myself - I still bump into walls, I just can't see myself doing it.

101 characters, one line. The classic power, ruined in the most pointless way
possible: invisibility that hides you from nobody but yourself, so you gain
nothing and still walk into every wall — you just can't watch yourself do it.

## Run it
